## Scope and plan

Audit the documentation after merged PRs #69, #71, #73, #75 and #77, using their changed files **and** the current implementation, scripts, workflows, published assets and tracked feature docs. Check setup/test commands, supported downloads, security claims, file-backed local libraries and release/publish instructions. Prefer small corrections to current guidance over rewriting historical plans or verification records. Do not delete review scratch notes in this issue.

1. Compare README and AGENTS.md to `package.json`, `.nvmrc`, native test/dev scripts, `electron-builder.json5`, release/verify workflows, actual GitHub assets and release script.
2. Compare current library and token guidance to `electron/main/local-library.ts`, `electron/main/github.ts`, app onboarding UI, `docs/library-working-copies.md` and `docs/library-first-command-storage.md`; distinguish historical plans in archived docs from current instructions.
3. Record discrepancies and limitations here, correct only current-facing statements, check Markdown targets and run practical type/test checks without opening normal app data or publishing releases.
4. Review each local `temp-` finding and the original review for uniquely retained decisions, exceptions, test gaps and follow-ups; report a deletion proposal separately and await confirmation.

## Review scratch preservation and deletion proposal

The original 2026-09-28 static review assessed **small public beta, not broad release-hardened launch**. It did not exercise cross-platform installers, reproduce an exploit, or complete end-to-end UX testing; advisory counts and Electron versions were time-specific. The five work items were tracked by issues #68, #70, #72, #74 and #76 and merged as PRs #69, #71, #73, #75 and #77. Decisions/exceptions and verification gaps are now preserved in their respective tracked feature docs; this historical scope/verdict and the token-at-rest caveat are retained here. No current packaged release was smoke-tested in this audit.

- `temp-1-security-dependencies.md`: advisory reachability, separate Electron risk, cadence and no audit exceptions are in `docs/dependency-security.md`; Linux fallback is now in `docs/schema.md`. Safe to delete after review.
- `temp-2-renderer-hardening.md`: window/IPC/CSP/URL decisions and remaining UI gaps are in `docs/renderer-hardening.md`; its extra hostile-resource and clipboard test limitations are now explicit there. Safe to delete after review.
- `temp-3-file-backed-command-sync.md`: fail-closed scan, watcher, content-vs-timestamp decisions, blocked-valid-edits tradeoff and non-backup index are covered by issue #72 and `docs/library-first-command-storage.md`. Safe to delete after review.
- `temp-4-release-verification.md`: Node/Electron ABI preparation, exact-tag gating, branch-protection limitation and unperformed installer checklist are in `docs/release.md`; release-manager conflict has follow-up #79. Safe to delete after review.
- `temp-5-maintainability-and-downloads.md`: published asset evidence, typed bridge decision and no line-count-only refactor are in `docs/preload-contract.md` and issue #76; UI smoke gaps are recorded there. Safe to delete after review.
- `review-2026-09-28-findings.md`: historical verdict, limited scope, lack of exploit proof and five findings are preserved above and in tracked issues/docs. Safe to delete after review.

None of these files was deleted. `.ideas/code-review-2026-03-17.md` is a separate ignored review scratch file of another date: **not part of this deletion proposal**. No other `temp*.md`/review-named files were found under the repository at audit time (excluding dependencies).

No installer GUI run, OS-native package launch, live GitHub auth, release tag, or publication was attempted. No `pnpm install --frozen-lockfile` was performed from a fresh Node 24 checkout in this audit; the prior CI record in `docs/release.md` supplies that evidence, not this local run.
